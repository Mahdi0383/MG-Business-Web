# MG Business Web

سامانه یکپارچه و ماژولار مدیریت کسب‌وکار MG.

## شروع سریع

نیازمندی‌ها: Node.js 20 یا جدیدتر و npm.

```bash
npm install
npm run dev
```

ساخت نسخه قابل انتشار:

```bash
npm run build
npm run preview
```

## وضعیت فعلی

- رابط فارسی و راست‌چین، واکنش‌گرا
- داشبورد اولیه و ناوبری ماژولار
- ثبت تراکنش درآمد و هزینه
- جست‌وجوی تراکنش‌ها و محاسبه مانده
- ذخیره‌سازی محلی برای کارکرد آفلاین اولیه

> داده‌های نسخه فعلی در مرورگر و دستگاه جاری ذخیره می‌شوند؛ همگام‌سازی چنددستگاهی و پایگاه داده مرکزی هنوز پیاده‌سازی نشده‌اند.
