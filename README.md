# MG Business Web

سامانه تحت وب مدیریت کسب‌وکار MG با رابط فارسی و راست‌چین.

## اجرای محلی در Termux یا رایانه

این نسخه فعلاً یک برنامه استاتیک HTML/CSS/JavaScript است و به Node.js، npm یا فرایند build نیاز ندارد.

~~~sh
pkg update -y
pkg install git python -y
git clone https://github.com/Mahdi0383/MG-Business-Web.git
cd MG-Business-Web
python -m http.server 8080 --bind 0.0.0.0
~~~

سپس در مرورگر همان دستگاه باز کنید: http://127.0.0.1:8080

برای دریافت آخرین تغییرات، در نشست جداگانه اجرا کنید:

~~~sh
cd ~/MG-Business-Web
git pull --ff-only
~~~

## قابلیت‌های موجود

- داشبورد واکنش‌گرا و فارسی (RTL)
- ناوبری ماژولار برای کافه، گیم‌نت، حسابداری، مشتریان، انبار، گزارش‌ها و تنظیمات
- ثبت و حذف تراکنش درآمد و هزینه، دسته‌بندی و جست‌وجو
- خروجی پشتیبان JSON از داده‌های مالی
- محاسبه مجموع درآمد، هزینه و مانده
- ذخیره‌سازی محلی تراکنش‌ها در مرورگر
- پوسته اولیه PWA و پشتیبانی از بارگذاری آفلاین فایل‌های اصلی

## محدودیت‌های فعلی

- ماژول‌های عملیاتی هنوز پیاده‌سازی نشده‌اند؛ صفحات آن‌ها فعلاً نمای توسعه هستند.
- داده‌ها فقط در مرورگر و دستگاه جاری ذخیره می‌شوند؛ همگام‌سازی چنددستگاهی و پایگاه داده مرکزی وجود ندارد.
- فونت آنلاین ممکن است بدون اینترنت در دسترس نباشد.
- این نسخه هنوز برای استفاده مالی/تجاری واقعی یا چندکاربره آماده انتشار نهایی نیست.
