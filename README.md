# MG Business Web

پلتفرم وب مستقل MG Business؛ هدف آن ارائه یک هسته یکپارچه برای مدیریت فروش، انبار، مشتریان، حسابداری، کافه/رستوران و گیم‌نت است.

## وضعیت توسعه
- رابط کاربری اولیه فارسی و RTL با React و Vite منتقل شده است.
- هسته اولیه API با ASP.NET Core 10 و لایه‌های Domain / Infrastructure ایجاد شده است.
- مدل‌های پایه کسب‌وکار و شعبه و تست‌های دامنه اضافه شده‌اند.
- SQLite برای توسعه محلی و PostgreSQL برای استقرار مرکزی پشتیبانی می‌شود.
- این پروژه هنوز نسخه عملیاتی یا آماده استفاده تجاری نیست؛ احراز هویت، مجوزها، جداسازی tenant، مهاجرت‌های پایگاه داده و ماژول‌های تجاری در حال طراحی و پیاده‌سازی مرحله‌ای هستند.

## اجرای رابط وب
```bash
npm install
npm run dev
```

ساخت production:
```bash
npm run build
```

## اجرای API
نیازمند .NET 10 SDK:
```bash
dotnet run --project backend/src/MG.Business.Api
```

مستندات API در [backend/README.md](backend/README.md) و اصول معماری در [docs/architecture/FOUNDATION.md](docs/architecture/FOUNDATION.md) قرار دارند.

## اصول غیرقابل مذاکره
- اطلاعات هر کسب‌وکار باید به‌صورت امن از سایر کسب‌وکارها جدا باشد.
- داده‌های مالی و موجودی باید قابل حسابرسی و دارای تاریخچه باشند.
- ثبت فروش، پرداخت، گردش موجودی و سند مالی باید سازگار و قابل بازیابی باشد.
- قابلیت‌های آفلاین باید صف عملیات پایدار و همگام‌سازی قابل تکرار داشته باشند.
- هیچ قابلیت نمایشی یا mock نباید به‌عنوان قابلیت عملیاتی معرفی شود.
