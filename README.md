# MG Business Web

نسخه وب مستقل پلتفرم یکپارچه MG Business.

## اجرای محلی
```bash
npm install
npm run dev
```

## ساخت
```bash
npm run build
npm run preview
```

## انتشار آزمایشی
این پروژه با React و Vite ساخته شده و خروجی استاتیک آن از طریق GitHub Actions روی GitHub Pages منتشر می‌شود. در تنظیمات مخزن، Pages را روی **GitHub Actions** قرار دهید.

نشانی مورد انتظار: https://mahdi0383.github.io/MG-Business-Web/

## وضعیت فعلی
این commit انتقال پیش‌نمایش اولیه از مخزن MG-Business-Platform به مخزن مستقل است. رابط فارسی RTL شامل داشبورد، صندوق آزمایشی، سفارش‌ها، کالا و انبار، مشتریان، نمای اولیه کافه و گیم‌نت، خلاصه مالی، گزارش‌ها و تنظیمات است. داده‌ها فقط در localStorage همان مرورگر ذخیره می‌شوند؛ این نسخه برای عملیات واقعی یا حسابداری رسمی آماده نیست.

## معماری هدف
- Frontend: React + TypeScript (مهاجرت مرحله‌ای از نمونه JavaScript) + Vite + PWA
- Backend: ASP.NET Core Web API
- Database: PostgreSQL مرکزی و SQLite برای حالت محلی/آفلاین
- قابلیت‌های هسته: چندمستاجری، چندشعبه‌ای، نقش‌ها و مجوزها، لایسنس ماژولار، همگام‌سازی آفلاین
- ماژول‌ها: POS، کالا و انبار، مشتریان، حسابداری، کافه/رستوران، گیم‌نت، سفارش آنلاین، گزارش‌ها و تنظیمات

GitHub Pages فقط frontend استاتیک را میزبانی می‌کند و جایگزین API یا پایگاه داده نیست. هر قابلیت عملیاتی باید با تست، اعتبارسنجی، کنترل دسترسی، مدیریت خطا و مستندات تکمیل شود.
